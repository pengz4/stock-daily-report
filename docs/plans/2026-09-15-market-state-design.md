# A 股大盘状态设计

## 目标

让日报读者在查看个股前，先了解 A 股市场整体环境。第一版同时使用主要指数表现和全市场涨跌广度，并保持结果可审计、可复用、不会因为单个数据源失败而阻断日报生成。

## 已确认决策

- 指数集合：上证指数、深证成指、创业板指、沪深 300、中证 1000。
- 实现路径：市场状态绑定现有 `MarketScanArtifact`，不新增独立的状态 artifact。
- 数据流：一次全市场 UniverseQuote 快照计算广度；同一次扫描获取指数历史；两者组合成不可变 `MarketState`。
- 日报 pipeline 只读取扫描 artifact，不在渲染阶段重复请求数据。
- 报告 JSON 保留原始字段、代码、版本和数据源；Markdown/HTML 使用中文可读标签。
- 市场状态位于报告头部元数据之后、全市场排名和个股分析之前。

## 数据模型

在 `MarketScanArtifact` 中新增可选 `market_state` 字段，兼容历史 artifact。`MarketState` 包含报告日期、生成时间、规则版本、指数记录、市场广度、整体状态和可读结论。

每个指数记录保存名称、代码、最新交易日、收盘价、日涨跌、20 日和 60 日均线关系、趋势标签和 provider。广度保存上涨/下跌/平盘数量、上涨/下跌占比、涨跌比、涨停/跌停数量（provider 未提供时为 null）、有效样本数、总样本数和数据源。

整体状态由固定规则判定：指数方向与广度一致时判定强势、偏强或偏弱、弱势；方向分歧时判定震荡；样本不足时判定数据不足。规则版本、指数配置和数据输入哈希参与 artifact 身份校验，防止旧状态被错误复用。

## 展示与降级

Markdown/HTML 新增“市场状态”区域，紧随报告元数据之后。先显示结论，再显示指数表现表和市场广度摘要。缺失字段显示“未提供”，不以 0 伪造数据。

指数全部失败但广度可用时显示“市场状态部分可用”；广度缺少涨跌幅但指数可用时保留指数结果并标注广度不可用；扫描 artifact 缺失、日期不符、版本不符或状态完全不可用时显示结构化的“市场状态不可用”，但继续生成自选股报告。provider 失败保留稳定的 provider、错误代码和原因。

现有“全市场排名”仍位于市场状态之后，自选股追踪和最后的全池速览顺序不变。

## 手机端 panel 布局

HTML 报告增加横向可滚动的 panel 导航和六个折叠区域，选项固定为：

1. 大盘
2. 多策略共识
3. 趋势策略
4. 均衡策略
5. 自选股追踪
6. 全池速览

使用原生 `<details>`/`<summary>`，不依赖 JavaScript；默认只展开“大盘”，导航使用锚点定位到对应 panel。这样手机端初始高度较短，同时保留键盘访问、复制和无脚本环境的可用性。Markdown 保持线性章节结构，不强行模拟 HTML panel。

## 验证范围

- `MarketState` 模型约束、旧 artifact 兼容和状态分类矩阵。
- 指数 provider 的字段映射、报告日期截断、均线计算和失败隔离。
- 扫描 artifact 序列化、输入哈希、配置/规则版本和日报复用判断。
- Markdown/HTML 展示顺序、中文标签、缺失值和 HTML/Markdown 转义。
- HTML panel 导航的六项顺序、默认展开状态、锚点和移动端样式。
- 全套现有测试作为合并门槛。
